# Домашнее задание к работе 8
## Условие задачи
Вычислите с использованием цикла for значение ряда, для заданных пользователем значений a и n

$$
\frac{1}{a} + \frac{1}{a^2} + \frac{1}{a^4}... + \frac{1}{a^{2^n}}
$$

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Ввести значения:
   - `a` — число a.
   - `n` — максимальная степень 2.
  
3. Создать переменные:
   - `result` = 0

4. Цикл-счетчик:
   - `i` = 0 - инициализация
   - `i` <= `n` - условие
   - `i`= `i` + 1 - шаг
  
5. Тело цикла:
   - `result` = `result` + $\frac{1}{a^{2^i}}$
  
6. Вывести результат вычислений.
7. **Конец**

## 2. Реализация программы

```C
#include <stdio.h>
#include <locale.h>
#include <math.h>

int main()
{
    setlocale(LC_CTYPE, "RUS.UTF-8");
  
    double a;
    int n;

    puts("1/a + 1/a^2 + 1/a^4 + ... + 1/a^2^n");
    puts("Введите число a:");
    scanf("%lf", &a);

    puts("Введите число n:");
    scanf("%d", &n);

    double result = 0;
    for (int i = 0; i <= n; i++)
    {
        result += 1 / pow(a, pow(2.0, (double)i));
    }
    
    printf("Результат: %f\n", result);

    return 0;
}
```
